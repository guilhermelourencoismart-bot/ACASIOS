# Install ACASIOS on iPhone or iPad

This fork is configured for:

- Repository: `guilhermelourencoismart-bot/ACASIOS`
- GUI: `https://guilhermelourencoismart-bot.github.io/ACASIOS/app/`
- Userscript: `https://guilhermelourencoismart-bot.github.io/ACASIOS/acas.user.js`

## GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose
`main` and the repository root (`/`). Wait for the Pages deployment to finish.

## Safari

1. Install Tampermonkey for iPhone/iPad or a userscript manager that implements
   Greasemonkey `GM_*` APIs.
2. Enable its Safari extension and grant access to the GUI and chess sites.
3. Open the userscript URL above and install it.
4. Open the GUI URL and keep that tab available while using a supported chess
   website in Safari. Native chess apps cannot be read by a browser userscript.

Use assistance only against bots, for analysis or where assistance is allowed.
